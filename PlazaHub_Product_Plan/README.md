# PlazaHub Product Planning Pack

> Historical planning pack retained for reference. The authoritative documentation is now in the project-root [docs/ directory](../docs/README.md). The local docs/ copies remain unchanged; use the canonical links below for ongoing work. New specifications are drafts, not business-policy approvals.

An editable, developer-friendly starting set of product documents for the Nigerian commercial-plaza SaaS.

**Prepared:** 2026-11-05  
**Status:** Founder-review draft; not a validated customer specification.

## Files

- [`docs/ROADMAP.md`](../docs/ROADMAP.md) — v0.1 validation through v3.0 roadmap, v1.0 workstreams and feature gates.
- [`docs/DECISIONS.md`](../docs/DECISIONS.md) — Fixed working decisions, open rules, proposed defaults and a decision template.
